- Sửa `BE/src/Domain/Repositories/ICustomizationRepository.cs`, `BE/src/Persistence/Repositories/CustomizationRepository.cs`: giữ `GetByIdAsync` tracked để mutate; thêm `ReadByIdAsync` no-tracking, `GetVersionAsync(Guid rootId, Guid versionId, CancellationToken ct)`, `GetPublicVersionAsync(Guid versionId, CancellationToken ct)` trả domain `PublishedCustomization` (root `Id`, `VersionId`, title/config/slug/version), và Stage/Add APIs cho version/alias. Public/list queries dùng `AsNoTracking`, projection phân trang, không load `ConfigJson`/template entity cho list; đọc template name bằng projection/join. Một command nghiệp vụ chỉ `SaveChangesAsync` một lần. Bắt `DbUpdateConcurrencyException` và unique constraint thành `409`, giữ dữ liệu đã lưu. Transaction cho save-working+snapshot và chọn/gỡ publication.
- Sửa `BE/src/Contract/Services/V1/Customizations/{Command,Query,Response}.cs`, `BE/src/Presentation/APIs/Customizations/CustomizationApi.cs`; thêm handler/validator dưới `BE/src/Application/UseCases/V1/Customizations/{Commands,Queries,Validators}/`. Payload create/save: `templateId,title,slug,configJson,clientDraftId` (UUID), `expectedRevision` (int khi update), `requestId` (UUID); version command dùng `expectedRevision,requestId` và working content. `CreateCustomizationCommand(...) : ICommand<CustomizationMutationResponse>`; `UpdateCustomizationCommand(...) : ICommand<CustomizationMutationResponse>`; `CreateCustomizationVersionCommand(...) : ICommand<CustomizationVersionMutationResponse>`; publish/unpublish commands tương ứng. Admin được xác định từ DB tại request, không nhận role/client user ID đáng tin từ body.
- Giữ envelope `Result.value`. Response mutate `{id,revision}`; create-version `{id,revision,versionId,versionNumber}`; version list `{id,customizationId,versionNumber,title,isPublic,publishedAtUtc,createdAtUtc,publicUrl}` không config; version detail thêm `configJson`. List `{data,total,page,pageSize}`. Public detail `{id,templateId,title,slug,configJson,versionId,versionNumber}`; không có owner/draft/private versions. `POST /`, `PUT /{id}` chỉ lưu working draft; `GET /{id}` owner/admin; `GET /{id}/versions`, `GET /{id}/versions/{versionId}` owner/admin; `POST /{id}/versions`; `PUT /{id}/publication`; `DELETE /{id}/versions/{versionId}/publication`; `DELETE /{id}/publication`; `GET /slug/{slug}`; `GET /slug/{slug}/versions/{number}`. Validate slug chuẩn lowercase URL, JSON object + field/size theo schema, trả lỗi đúng field. `409` cho revision/slug/request conflict; retry cùng `ClientDraftId` hoặc `RequestId` trả lại kết quả cũ idempotent, không tạo bản mới. Delete site giữ data/response và đóng mọi URL public. Gỡ version chính để main URL 404, không tự chọn bản thay thế. Version từng public tiếp tục ở URL riêng cho tới khi gỡ.
